# Acts Journeys Map

An interactive map of the journeys of Paul, Barnabas and other disciples in the book of Acts.

- **Map:** 15 color-coded journeys with companions and Bible references
- **Churches:** each place's church against the Church Waffle (solid ring = church, dashed = group)
- **Suffering:** persecution events and what followed
- **Up close:** venues, audiences and strategy for each stop
- **Four Fields:** progression of each place through Entry, Gospel, Discipleship and Church

Single static file (`index.html`), no build step. Live site: https://jtliner925.github.io/acts-journeys-map/
